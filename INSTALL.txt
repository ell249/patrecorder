PAT Recorder
Installation Instructions
---------------------------------------------

This document describes how to install and run PAT Recorder on a local machine or server. It includes system requirements, dependency installation, database setup, and application startup.

---------------------------------------------
1. System Requirements
---------------------------------------------

Operating System:
- Ubuntu or Debian (recommended)
- macOS
- Windows (via WSL2 for full PDF support)

Required Software:
- Python 3.9 or newer
- MySQL 5.7+ or MariaDB 10.4+
- WeasyPrint dependencies (Cairo, Pango, GObject)

---------------------------------------------
2. Install System Dependencies
---------------------------------------------

Ubuntu / Debian:
    sudo apt update
    sudo apt install -y python3 python3-venv python3-pip libffi-dev libcairo2 libpango-1.0-0 libpangocairo-1.0-0 gobject-introspection libgirepository1.0-dev

macOS (Homebrew):
    brew install python3 cairo pango gobject-introspection

Windows:
Use WSL2 with Ubuntu for compatibility:
    wsl --install

---------------------------------------------
3. Prepare the Project
---------------------------------------------

Place the project folder anywhere on your system:

    patrecorder/

---------------------------------------------
4. Create Python Virtual Environment
---------------------------------------------

    cd patrecorder
    python3 -m venv venv
    source venv/bin/activate
    pip install -r requirements.txt

---------------------------------------------
5. Install and Configure MySQL
---------------------------------------------

Ubuntu:
    sudo apt install mysql-server

macOS:
    brew install mysql
    brew services start mysql

Log into MySQL:
    mysql -u root -p

Run the SQL setup files:

    SOURCE sql/create_database.sql;
    SOURCE sql/create_tables.sql;
    SOURCE sql/insert_default_retest_rules.sql;

This creates the required base tables:
- appliance
- tester
- test_record
- test_photo
- retest_rule

---------------------------------------------
6. Configure Database Credentials
---------------------------------------------

Copy the example config and edit it:

    cp config.example.py config.py

Edit config.py and update the database URI:

    SQLALCHEMY_DATABASE_URI = "mysql+pymysql://USERNAME:PASSWORD@localhost/test_and_tag"

Replace USERNAME and PASSWORD with your MySQL credentials.

---------------------------------------------
7. Run Database Migrations
---------------------------------------------

After the base tables are created, run Flask-Migrate to apply any
additional schema changes (including the repair tables):

    export FLASK_APP=app.py
    flask db upgrade

If this is a fresh install with no migrations folder yet:

    flask db init
    flask db upgrade

---------------------------------------------
8. Create Uploads Directories
---------------------------------------------

Ensure the uploads folders exist for test and repair photos:

    mkdir -p static/uploads/tests
    mkdir -p static/uploads/repairs

---------------------------------------------
9. Run the Application
---------------------------------------------

    export FLASK_APP=app.py
    flask run

The application will be available at:

    http://127.0.0.1:5000

---------------------------------------------
10. Development Mode (Optional)
---------------------------------------------

    export FLASK_ENV=development
    flask run

This enables automatic reload on file changes.

---------------------------------------------
11. Troubleshooting
---------------------------------------------

PDF generation errors:
Install missing libraries:

Ubuntu:
    sudo apt install libcairo2 libpango-1.0-0 libpangocairo-1.0-0

macOS:
    brew install cairo pango

MySQL connection refused:
    sudo service mysql status

Permission denied on uploads:
    chmod -R 755 static/uploads

Migration errors on fresh install:
If Flask-Migrate reports "can't locate revision", delete the migrations/
folder and re-run:
    flask db init
    flask db upgrade

---------------------------------------------
12. Next Steps
---------------------------------------------

After installation you can:
- Add appliances
- Record tests under AS/NZS 3760, 5761, or 5762
- Log repairs against appliances (with photos)
- Upload photos for tests and repairs
- Export PDF test certificates and repair history reports
- Use the dashboard to track appliances due for testing,
  including those repaired since their last test
- Use fuzzy search across assets and tag numbers
